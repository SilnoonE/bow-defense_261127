Bow Defense 2.0 — 2026-11-28 수정 및 출시 기록

출시: 버전 2.0.0 / 코드 10. 모든 대상 국가, 100% 전체 출시로 Google 검토 전송 완료.
콘솔은 검토 중으로 표시하며 초기 자동 검사가 진행 중이다. 실제 스토어 배포 완료를 의미하지 않는다. 관리형 게시가 꺼져 있어 승인 후 자동 게시된다.
43개 언어 출시 노트 입력. 지원 기기 감소 0. 경고는 가독화 파일 미첨부 1개이며, 난독화를 사용하지 않아 해당 파일이 생성되지 않는 구성이다.

수정 전 → 수정 후
1. 벽시계/프레임 의존 전투 → 1/60초 고정 시뮬레이션, 실제 전투 시간만 누적, 정지 중 효과와 시간 유지.
2. 일부 점수만 이어하기 → 전체 전투 상태 원자 저장, 세션 ID 기반 복원, 언어 변경/화면 재생성 복원.
3. 이어하기 보상 중복 가능 → 동일 세션 기록 갱신, 누적 차액 지급, 업적 보상과 이어하기 비용 중복 방지.
4. 시간에 따라 숫자만 바뀌던 웨이브 → 8개 전투 구간, 4번째 정예, 마지막 보스, 클리어 후 무한 모드.
5. 점수 연동 적 HP 급증 → 웨이브 예산과 적 조합으로 난이도 제어.
6. 자동 수치 성장 → 첫 25초 3택1 선택, 관통/냉기/화염/연사 총 12카드, 중첩 한도와 진화 조건.
7. 같은 이동 방식의 적 3종 → 기존 적 유지 + 방패병/소환사/보스, 신규 투명 PNG 3장 적용.
8. 무료 전투 스킬 없음 → 20초 충격파, 관통/경직/밀치기. 보스 돌진 예고, 소환, 보호막/노출 주기.
9. 비슷한 활 동작 → 플레이로 해금하는 속사/관통/제어 역할. 기존 유료 활 ID·소유권·연사 혜택 유지.
10. 물약 500/강화 800/감속 1200골드 → 60/90/100골드. 물약 회복 1→3. 강화 피해 소수 처리.
11. 빈약한 명중 표현 → 피격 플래시, HP, 파편, 콤보, 명중/처치 음향, 흔들림 설정.
12. 미갱신 업적 진행 → 현재/목표 표시, 홈 다음 목표 3개, 상점 구매 즉시 집계, 준비물 지출을 세션에 반영.
13. 조건식 AI 분석 → 이번 판 빌드/패배 원인/이전 최고 대비/다음 목표를 표시하는 전투 피드백.
14. 결과 전 강제 전면 광고 → 결과 즉시 표시. 테스트 빌드는 광고 요청 비활성화. 광고 클릭 0회.
15. 기존 데이터 → Room 1→2→3 명시적 이전. 기록·업적·구매·골드 보존. 파괴적 초기화 없음.
16. 다국어 누락 → 한국어/영어/일본어/중국어/스페인어 신규 기능 문구와 업적 보완, 서식 오류 수정.
17. 클리어에도 GAME OVER 제목 → 클리어 제목과 색상을 별도 표시.

검증
- 최종 assembleDebug, assembleDebugAndroidTest, bundleRelease, lintRelease 성공.
- 엔진 단위 테스트 11개 통과: 30/60/120 FPS 동일성, 정지 시간, 선택 시점/복원, 카드 조건/상한, 소수 피해, 이어하기, 스킬 쿨타임, 명중률, HP 독립성, 챕터 완료, 세 역할 클리어.
- Android 기기 테스트 2개 통과: 기존 DB 마이그레이션, 기록/보상/구매/이어하기 중복 방지.
- 광고 없는 에뮬레이터에서 조준 발사, 충격파, 일시정지, 언어 변경 후 상태 복원, 3택1 선택, 사망/결과/재도전 동선 확인.
- 자동 조준 시뮬레이션의 세 역할 챕터 완료 시간 약 243~255초. 사람 플레이 난이도 연구 결과가 아니다.
- 기존 업로드 인증서와 동일한 서명 확인, jarsigner 검증 통과.

구현 조정 및 검증 한계
성장 선택은 웨이브 경계 외에도 32초 주기로 제공한다. 보스 경직은 충격파와 제어 효과로 대응한다. 작은 사용자 그룹 연구, 실제 결제 거래, 최소 사양 실기기 장시간 성능 계측은 수행하지 않았다. 이를 완료한 것으로 보고하지 않는다. 기존 정적 분석 경고는 남아 있지만 린트 오류는 0개다.
공개 소스는 실제 앱 이름, 패키지, 광고 식별자와 비밀 파일을 제외한 수정 전후 참고용 스냅샷이다.
